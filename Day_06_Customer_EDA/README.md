# Day 6 – Customer Purchase Behavior EDA

## Objective
Analyze customer demographics and spending behavior using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Insights
- Majority customers are aged 20–35.
- Female customers show higher spending scores.
- Income is not directly proportional to spending.

## Outcome
EDA helps businesses identify high-value customer segments.
